# GoChat — Fullstack Web Chat Application

Полноценное Fullstack-приложение для обмена сообщениями, включающее пользовательский интерфейс, безопасный производительный бэкенд на чистом Go и автоматизированную инфраструктуру для развертывания.

## 🛠 Стек технологий

- **Backend:** Go (Golang) — стандартная библиотека `net/http`
- **Безопасность:** `golang.org/x/crypto/bcrypt` (хэширование паролей)
- **Database:** PostgreSQL (чистый SQL без ORM)
- **Frontend:** HTML / CSS / JavaScript
- **DevOps:** Docker, Docker Compose

## 🚀 Особенности и архитектура проекта

- **Zero Frameworks:** Серверная логика написана на чистом Go с использованием стандартного пакета `net/http`. Это минимизирует внешние зависимости и обеспечивает максимальную производительность.
- **Безопасность данных:** Реализована надежная аутентификация. Пароли пользователей никогда не хранятся в открытом виде — они хэшируются с солью с помощью алгоритма `bcrypt`.
- **Работа с БД:** Спроектирована реляционная структура данных в PostgreSQL. Написаны оптимизированные SQL-запросы для реализации полного цикла CRUD (создание, чтение, обновление и удаление пользователей, чат-комнат и сообщений).
- **Инфраструктура как код:** Все компоненты приложения полностью контейнеризированы. Локальное окружение поднимается одной командой.

## 📦 Быстрый запуск

Для запуска всего проекта вам понадобятся только установленные **Git** и **Docker**.

1. Клонируйте репозиторий на свой компьютер:
   ```bash
   git clone https://github.com/pavlovvity-netizen/GoChat
   cd GoChat
   cp .env.example .env
   ```

2. Запустите приложение и базу данных в Docker-контейнерах:
   ```bash
   docker-compose up --build
   ```

3. После успешной сборки и запуска откройте браузер и перейдите по адресу:
   ```text
   http://localhost:8080
   ```
   *(Если в вашем коде или Docker-контейнере настроен другой порт, измените `8080` на ваш).*

## 📂 Структура проекта

В проекте реализована многослойная архитектура (Clean Architecture), что обеспечивает слабую связность компонентов и простоту тестирования:

```text
├── domain/           # Бизнес-логика и описание сущностей (моделей) приложения
├── frontend/         # Клиентский интерфейс (Frontend-часть приложения)
├── handler/          # Слои доставки (HTTP-хендлеры, маршрутизация запросов)
├── repository/       # Слой работы с базой данных (прямые SQL-запросы к PostgreSQL)
├── service/          # Реализация core-логики и бизнес-правил чата
├── .env.example      # Шаблон конфигурационного файла для переменных окружения
├── .gitignore        # Исключение временных и конфиденциальных файлов из Git
├── Dockerfile        # Инструкция для контейнеризации Go-приложения
├── docker-compose.yml# Манифест для одновременного запуска Go-сервера и PostgreSQL
├── go.mod / go.sum   # Управление зависимостями проекта
├── main.go           # Точка входа в приложение (инициализация слоев и запуск сервера)
└── schema.sql        # Скрипт инициализации структуры БД (таблицы, индексы)
```
